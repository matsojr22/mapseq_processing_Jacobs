# Chapter 8: Output Files and Interpretation

## Overview

This chapter describes all output files generated by the MAPseq processing pipeline, their structure, and how to interpret the results.

## Output Directory Structure

```
02_output/
├── {age}/                          # P3, P12, P20, P60
│   └── {parameterization}/         # Filter parameter set
│       ├── analysis/
│       │   ├── uniform/           # Uniform model results
│       │   ├── region_specific/   # Region-specific model results
│       │   └── correlated/       # Correlated model results
│       ├── {sample}_*.csv         # Per-sample outputs
│       └── {sample}_*.png         # Visualization files
└── {parameterization}_helpers/    # Helper script outputs
    ├── 01_motif_analysis_per_animal/
    ├── 05_motif_analysis/
    └── ...
```

## Main Processing Outputs

### Per-Sample Files

**Location**: `{out_dir}/`

#### Filtered Matrix

**File**: `{sample}_Filtered_Matrix.csv`

**Content**: Quality-filtered UMI count matrix

**Columns**:
- Barcode identifiers (if preserved)
- Target region columns with filtered UMI counts
- Values < threshold set to zero

**Use**: Verify filtering quality, check data structure

#### Normalized Matrix

**File**: `{sample}_Normalized_Matrix.csv`

**Content**: Row-normalized matrix (each row sums to 1 after normalization by max)

**Columns**: Same as filtered matrix

**Use**: Relative projection strengths per cell

#### UMI Total Counts

**File**: `{sample}_UMI_Total_Counts.csv`

**Content**: Summed UMI counts per region

**Columns**:
- `Region`: Region name
- `UMI_Sum`: Total UMI counts for that region

**Use**: Check overall projection levels per region

#### Region-Specific Probabilities (Anchor Model)

**File**: `{sample}_Region-specific_Probabilities_N0based.csv`

**Content**: Region-specific projection probabilities (if `--is-anchor-model`)

**Columns**:
- `Region`: Region name
- `Probability`: pᵢ = Nᵢ/N₀
- `N0`: Estimated population size

**Use**: Anchor model probabilities for cross-cohort comparison

#### Conditional Probability Matrix (Anchor Model)

**File**: `{sample}_Conditional_Probability_Matrix.csv`

**Content**: P(B|A) matrix for correlated model (if `--is-anchor-model`)

**Structure**: 
- Rows: Region A (given)
- Columns: Region B (target)
- Values: P(B|A) = probability of projecting to B given projection to A

**Use**: Anchor correlation structure for cross-cohort comparison

### Analysis Outputs

**Location**: `{out_dir}/analysis/{model}/`

#### Upsetplot CSV

**File**: `{sample}_upsetplot_{model}.csv`

**Content**: Core motif analysis results

**Columns**:
- `Motifs`: List of regions in motif (e.g., "['al', 'lm']")
- `Observed`: Count of neurons with this motif
- `Expected`: Model-predicted count
- `Expected SD`: Standard deviation of expected count
- `Effect Size`: log₂(Observed/Expected)
- `P-value`: Two-tailed binomial test p-value
- `Degree`: Number of regions in motif
- `Group`: Significance group (1-4)

**Interpretation**:
- **Group 1** (Red): Significantly over-represented
- **Group 2** (Blue): Significantly under-represented
- **Group 3** (Black): Non-significantly over-represented
- **Group 4** (Black): Non-significantly under-represented

**Use**: Primary data for motif analysis, stability analysis

#### Effect Significance Plot

**File**: `{sample}_effect_significance_{model}.png`

**Content**: Volcano plot showing effect size vs. p-value

**Axes**:
- X-axis: Effect Size (log₂(Observed/Expected))
- Y-axis: -log₁₀(P-value)

**Colors**:
- Red: Significantly over-represented (Group 1)
- Blue: Significantly under-represented (Group 2)
- Black: Non-significant (Groups 3 & 4)

**Use**: Quick visual identification of significant motifs

#### Per-Cell Projection Strength

**File**: `{sample}_per_cell_proj_strength_{model}.png`

**Content**: Individual cell projection patterns

**Use**: Understanding heterogeneity and cell-level variation

#### 2-Region Motif Graph

**File**: `{sample}_panel_g_broadcasting_from_canonical_{model}.svg`

**Content**: Network graph showing pairwise relationships between target regions

**Structure**:
- Nodes: Regions (RSP, PM, AM, AL, LM)
- Edges: 2-region motifs
- Colors: Significance (red=overrepresented, blue=underrepresented, black=not significant)

**Use**: Understanding relationships between pairs of target regions

#### Projection Summary

**File**: `projection_summary.csv`

**Content**: Comprehensive summary metrics for each sample

**Columns**:
- `Sample`: Sample name
- `Model`: Model type (uniform, region_specific, correlated)
- `injection_min`: Injection UMI threshold used
- `target_umi_min`: Target UMI threshold used
- `p_e`: Uniform edge probability (if applicable)
- `N0`: Estimated population size
- `consensus_k`: Most common motif degree
- `motif_counts`: Counts by motif degree
- Additional summary statistics

**Use**: High-level summary statistics and parameter tracking

## Helper Script Outputs

### Script 01: Per-Animal Analysis

**Location**: `02_output/{parameterization}_helpers/01_motif_analysis_per_animal/{model}/`

**Key Files**:
- Kruskal-Wallis results (CSV/text)
- JSD comparison matrices
- Bar plots with SEM across animals

**Interpretation**:
- **Kruskal-Wallis p < 0.05**: Motif frequency changes significantly across ages
- **JSD < 0.05**: Very similar distributions (stable)
- **JSD > 0.2**: Large difference (unstable)

### Script 05: Motif Analysis

**Location**: `02_output/{parameterization}_helpers/05_motif_analysis/`

**Key Files**:
- `motif_percent_matrix_by_age_{model}.csv`
  - Rows: Motifs
  - Columns: Ages (P12, P20, P60)
  - Values: Percentage of observed motifs
- `motif_transition_significance_summary_{model}.txt`
  - Per-motif transition comparisons with JSD and significance flags

**Interpretation**:
- **Percentage changes**: Quantitative changes in motif frequencies
- **Significance flags**: Which transitions show significant changes

### Script 07: Trajectories

**Location**: `02_output/{parameterization}_helpers/07_motif_significange_trajectories/{model}/`

**Key Files**:
- `combined_effect_sizes_{model}.csv`
  - Columns: `Motif_Label`, `Effect Size`, `Stage`, `Significant`, `Observed`
  - Tracks effect sizes across developmental stages
- `transition_significance.csv`
  - Columns: `Motif`, `Transition`, `P-value`, `Significant`, `Delta_Effect_Size`, `SE_delta`, `P_value_adjusted`
  - P-values for each transition (P3→P12, P12→P20, P20→P60). **Significant** may reflect FDR-adjusted p when helper 07 is run with `--use_fdr_for_significant`.

**Interpretation**:
- **Effect Size Range**: max(effect) - min(effect) across stages
  - Range > 1.0: Large changes in deviation from model
- **Transition Significance**: p < 0.05 indicates significant transition

### Script 15: Volcano Trajectories (v2.0)

**Location**: `02_output/{parameterization}_helpers/15_volcano_trajectories/{model}/`

Script 15 now includes multiple citable statistical methods for trajectory significance testing. All results are organized in subdirectories by method.

#### Directory Structure

```
15_volcano_trajectories/{model}/
├── per_motif_plots/           # Individual trajectory plots
├── quadrant_change/           # Quadrant-based summary plots
├── permutation/               # Permutation test results
├── fda/                       # FDA test results
├── mixed_effects/             # Mixed-effects model results
├── bootstrap_ci/              # Bootstrap CI (if enabled)
├── distance_metrics/          # Standardized distance metrics
├── method_comparison/         # Cross-method comparison
└── change_criteria_comparison.csv  # Legacy comparison file
```

#### Permutation Test Results

**File**: `permutation/permutation_test_results.csv`

**Columns**:
- `Motif`: Motif label
- `observed_stat`: Observed total variation (sum of |diff| between consecutive stages)
- `null_mean`, `null_sd`: Mean and SD of null distribution (from permuted data)
- `p_value`: Raw p-value (proportion of permuted stats ≥ observed)
- `p_value_fdr`: FDR-adjusted p-value (Benjamini-Hochberg)
- `significant`: True if p_value_fdr ≤ 0.05

**Interpretation**:
- **p_value < 0.05**: Trajectory shows more temporal variation than expected by chance
- **observed_stat >> null_mean**: Strong evidence of temporal change
- Use `significant` column for formal hypothesis testing (accounts for multiple testing)

#### FDA Test Results

**File**: `fda/fda_trajectory_significance.csv`

**Columns**:
- `Motif`: Motif label
- `fda_statistic`: Combined roughness + range statistic
- `null_mean`, `null_sd`: Mean and SD of null distribution
- `p_value`: Raw p-value
- `p_value_fdr`: FDR-adjusted p-value
- `significant`: True if p_value_fdr ≤ 0.05

**Interpretation**:
- Tests whether trajectory differs from a flat (constant) function
- Higher `fda_statistic` indicates more non-constant behavior
- Complements permutation test by focusing on trajectory shape

#### Mixed-Effects Model Results

**Files**:
- `mixed_effects/mixed_effects_summary.csv`: Overall model results
- `mixed_effects/mixed_effects_random_effects.csv`: Per-motif random intercepts

**mixed_effects_summary.csv Columns**:
- `stage_coefficient`: Effect of stage on effect_size (slope)
- `stage_pvalue`: P-value for stage coefficient
- `model_converged`: Whether the model successfully converged

**mixed_effects_random_effects.csv Columns**:
- `Motif`: Motif label
- `random_intercept`: Motif-specific deviation from population mean

**Interpretation**:
- `stage_pvalue < 0.05`: Stage significantly affects effect sizes across all motifs
- Large `random_intercept` values identify outlier motifs (above or below population trend)

#### Bootstrap CI Results

**File**: `bootstrap_ci/quadrant_bootstrap_ci.csv` (if `--bootstrap_ci` enabled)

**Columns**:
- `Motif`, `Stage`: Identifiers
- `quadrant_raw`: Original quadrant classification (sig_pos, sig_neg, not_sig)
- `prop_sig_pos`, `prop_sig_neg`, `prop_not_sig`: Bootstrap proportions
- `quadrant_robust`: "sig_pos", "sig_neg", "not_sig", or "uncertain"

**Interpretation**:
- `quadrant_robust = "uncertain"`: Point is near classification boundary; conclusion unstable
- High `prop_*` values (>0.95) indicate confident classification
- Focus on trajectories where most stages have `quadrant_robust != "uncertain"`

#### Distance Metrics Results

**File**: `distance_metrics/distance_comparison.csv`

**Columns**:
- `Motif`: Motif label
- `path_length_raw`: Original (unstandardized) Euclidean path length
- `path_length_zscore`: Z-score standardized path length
- `path_length_mahalanobis`: Mahalanobis distance path length
- `effect_size_range`, `effect_size_sd`, `effect_size_total_variation`
- `significance_range`, `significance_sd`, `significance_total_variation`
- `*_pct`: Percentile ranks (0-100) for each metric

**Interpretation**:
- **Prefer `path_length_zscore` over `path_length_raw`**: Standardization addresses scale mixing
- **High `effect_size_range_pct` (>90)**: Top 10% of motifs by effect size change
- Use `effect_size_total_variation` for monotonic vs. oscillatory trajectories

#### Method Comparison Summary

**Files**:
- `method_comparison/all_methods_summary.csv`: One row per motif with all method results
- `method_comparison/method_agreement_matrix.csv`: Pairwise agreement rates
- `method_comparison/significant_by_method.csv`: Lists of significant motifs per method

**all_methods_summary.csv Key Columns**:
- `quadrant_change`, `quadrant_change_filtered`, `centroid_dramatic`: Legacy methods
- `permutation_significant`, `permutation_pvalue_fdr`: Permutation test results
- `fda_significant`, `fda_pvalue_fdr`: FDA test results
- Distance metrics from `distance_comparison.csv`

**method_agreement_matrix.csv**:
- Rows/columns: Method names
- Values: Percentage agreement (both true or both false)
- **>80% agreement**: Methods give consistent results
- **<60% agreement**: Results depend on method choice; investigate further

**Interpretation Workflow**:
1. Start with `permutation_significant` or `fda_significant` for formal testing
2. Check `method_agreement_matrix.csv` for robustness
3. Use `all_methods_summary.csv` to filter motifs that are significant by multiple methods
4. For uncertain cases, check `bootstrap_ci` to assess classification confidence

#### Legacy Files

**File**: `change_criteria_comparison.csv`

**Content**: Original comparison metrics (retained for backward compatibility)

**Columns**:
- `Motif`, `quadrant_change`, `centroid_dramatic_full`, `centroid_dramatic_no_P3`
- `path_length`, `effect_size_range`, `path_length_pct`, `effect_size_range_pct`

**Note**: For publication, prefer the new statistical methods in `method_comparison/` over these legacy metrics.

## Interpreting Results

### Motif Significance

**Over-represented Motifs** (Effect Size > 0, p < α_corrected):
- Occur more frequently than expected by chance
- May indicate biological preference or constraint

**Under-represented Motifs** (Effect Size < 0, p < α_corrected):
- Occur less frequently than expected by chance
- May indicate biological avoidance or incompatibility

**Non-significant Motifs** (p ≥ α_corrected):
- Frequency matches model expectations
- No evidence for non-random organization

### Stability Analysis

**Model-Independent Metrics** (Kruskal-Wallis, JSD):
- Test observed frequencies directly
- **Stable**: p ≥ 0.05, JSD < 0.05
- **Unstable**: p < 0.05, JSD > 0.2

**Model-Dependent Metrics** (Effect Size Trajectories):
- Test deviations from model predictions
- **Stable**: Effect size range < 1.0
- **Unstable**: Effect size range > 1.0

**Transition Significance** (Fisher's Exact Test):
- Tests proportion changes between consecutive stages
- **Significant**: p < 0.05 indicates transition shows change

### Effect Size Interpretation

| Effect Size | Interpretation |
|-------------|----------------|
| > 1.0 | Large over-representation (>2× expected) |
| 0.5 to 1.0 | Moderate over-representation |
| 0 to 0.5 | Small over-representation |
| ≈ 0 | Matches expectation |
| -0.5 to 0 | Small under-representation |
| -1.0 to -0.5 | Moderate under-representation |
| < -1.0 | Large under-representation (<0.5× expected) |

### Comparing Models

**Agreement Across Models**:
- If multiple models agree on significance → robust finding
- If models disagree → investigate further (may indicate model sensitivity)

**Model Fit Quality**:
- **Good fit**: <10% of motifs significant
- **Poor fit**: >80% of motifs significant (suggests model misspecification)

## Common Output Patterns

### Pattern 1: High Stability

**Characteristics**:
- Kruskal-Wallis: p ≥ 0.05 for most motifs
- JSD: < 0.05 for most transitions
- Effect size ranges: < 1.0 for most motifs

**Interpretation**: Motif frequencies remain stable across development

### Pattern 2: Selective Changes

**Characteristics**:
- Kruskal-Wallis: p < 0.05 for subset of motifs
- Transition significance: Some transitions significant, others not
- Effect size ranges: Variable across motifs

**Interpretation**: Specific motifs show developmental changes

### Pattern 3: Model Mismatch

**Characteristics**:
- High percentage of significant motifs (>80%)
- Consistent under-representation (suggests model underestimates)
- Effect sizes large but stable across ages

**Interpretation**: Model assumptions violated (e.g., independence), but patterns are stable

## Quality Control

### Check Output Completeness

1. **Main processing**: Verify all expected files exist
2. **Helper scripts**: Check for error messages in outputs
3. **File sizes**: Ensure files are not empty
4. **Column counts**: Verify expected columns present

### Verify Results

1. **Effect sizes**: Check for reasonable values (typically -5 to +5)
2. **P-values**: Verify range [0, 1]
3. **Expected counts**: Should be positive and reasonable
4. **Motif counts**: Should match observed counts

### Common Issues

**Issue**: Empty output files
- **Cause**: No data passed filtering
- **Solution**: Check filtering parameters, verify input data

**Issue**: All motifs significant
- **Cause**: Model misspecification or data quality issues
- **Solution**: Check model assumptions, verify data quality

**Issue**: Missing helper script outputs
- **Cause**: Dependencies not met or script errors
- **Solution**: Check execution order, review error logs

## Supporting Tools and Utility Scripts

After main processing and helper scripts, you can use these utilities for quality control, figure generation, and conclusions:

### postprocessing_checks.py

Quality control checker that analyzes processing outputs and generates a QC report.

**Purpose**: Analyze log files for errors and warnings, verify output file structure and completeness, generate a human-readable QC report with statistics and recommendations.

**Usage**:
```bash
python postprocessing_checks.py [--repo_root REPO_ROOT] [--log_file LOG_FILE] [--output OUTPUT] [--base_output_dir BASE_OUTPUT_DIR]
```

**Main arguments**: `--repo_root` (repository root), `--log_file` (processing log), `--output` (report path), `--base_output_dir` (base output directory). Run with `--help` for full options.

### figure_generation/generate_figure_from_outputs.py

Generates publication-ready multi-panel figures from pipeline outputs.

**Purpose**: Create figure matrices organized by age group (p3, p12, p20, p60), combining outputs from main processing and helper scripts (pie charts, heatmaps, significance plots).

**Usage**:
```bash
python figure_generation/generate_figure_from_outputs.py [--parameterization PARAM] [--output_dir OUTPUT_DIR]
```

**Output**: Figures saved to `figure_generation/generated_figures/` (or specified `--output_dir`). Run with `--help` for full options.

### Conclusions scripts (extract_stability_data.py, generate_conclusions.py)

Extract stability analysis data and generate a conclusions markdown report. These scripts may live under `docs_temporary/conclusions/scripts/` in the repository.

**extract_stability_data.py**: Extracts Kruskal-Wallis results, transition significance, motif matrices, and divergence metrics from pipeline outputs; writes structured JSON. Arguments: `--base_dir`, `--output_file`.

**generate_conclusions.py**: Reads the extracted JSON and generates a markdown conclusions document with formatted statistics and significance indicators. Arguments: `--input_file`, `--output_file`.

Run each script with `--help` for full usage. See the repository README for current paths and examples.
