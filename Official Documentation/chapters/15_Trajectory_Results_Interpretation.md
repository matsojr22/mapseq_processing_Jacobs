# Trajectory Results Interpretation Guide

This guide provides a statistical interpretation framework for the volcano trajectory analysis outputs generated by Script 15. It explains how to interpret each method's results, when to use different filtering criteria, and how to draw defensible conclusions for publication.

---

## Overview of Analytical Methods

Script 15 provides **multiple analytical approaches** for detecting significant trajectory changes across developmental stages:

| Method | Type | Statistical Rigor | Output File |
|--------|------|-------------------|-------------|
| Quadrant Change | Descriptive | Not a formal test | `change_criteria_comparison.csv` |
| Quadrant Filtered | Descriptive + filtering | Not a formal test | `change_criteria_comparison.csv` |
| Permutation Test | Formal hypothesis test | Publication-ready | `permutation/permutation_test_results.csv` |
| FDA Trajectory Test | Formal hypothesis test | Publication-ready | `fda/fda_trajectory_significance.csv` |
| Mixed-Effects Model | Formal regression | Publication-ready | `mixed_effects/mixed_effects_summary.csv` |
| Spearman Trend Test | Formal hypothesis test | Publication-ready | `trend_analysis/spearman_trend_results.csv` |
| Linear Trend Test | Formal regression | Publication-ready | `trend_analysis/linear_trend_results.csv` |
| Direction Test | Formal binomial test | Publication-ready | `trend_analysis/direction_test_summary.csv` |

### Method Selection Guide

**For publication claims about individual motifs**: Use permutation test, FDA, or Spearman trend test. These provide formal hypothesis tests with proper null distributions and FDR correction.

**For detecting monotonic trends**: Use Spearman test (more sensitive to ordered changes than permutation test).

**For quantifying trend magnitude**: Use linear regression slopes from the trend analysis.

**For population-level directional bias**: Use the binomial direction test.

**For exploratory analysis**: Quadrant change methods can identify candidate motifs for further investigation.

**For visualization**: Distance metrics provide continuous rankings that avoid arbitrary binary cutoffs.

## Interpreting Permutation Test Results

The permutation test evaluates whether each motif's trajectory shows more variation than expected by chance.

### File: `permutation/permutation_test_results.csv`

| Column | Description |
|--------|-------------|
| `Motif` | Projection pattern identifier |
| `observed_stat` | Total variation in effect size across stages |
| `null_mean` | Mean of null distribution from permutations |
| `null_sd` | Standard deviation of null distribution |
| `p_value` | One-tailed p-value (proportion of null ≥ observed) |
| `p_value_fdr` | FDR-corrected p-value (Benjamini-Hochberg) |
| `significant` | Boolean: FDR p-value < 0.05 |

### Interpretation

- **significant = True**: The motif's trajectory variation is unlikely to arise from random stage assignment. This is a defensible claim for publication.
- **significant = False**: The observed trajectory pattern cannot be distinguished from random variation.
- **Low raw p-value but non-significant after FDR**: Suggestive but not conclusive; may warrant follow-up with larger sample sizes.

### Statistical Assumptions

1. Stages are exchangeable under the null hypothesis
2. Motifs are tested independently
3. Effect sizes are comparable across stages

## Interpreting FDA Trajectory Results

Functional Data Analysis treats each trajectory as a smooth function and tests for non-constant behavior using a roughness statistic.

### File: `fda/fda_trajectory_significance.csv`

| Column | Description |
|--------|-------------|
| `Motif` | Projection pattern identifier |
| `fda_statistic` | Roughness statistic (sum of squared second differences) |
| `null_mean` | Mean roughness under permutation null |
| `null_sd` | Standard deviation of null distribution |
| `p_value` | One-tailed p-value |
| `p_value_fdr` | FDR-corrected p-value |
| `significant` | Boolean: FDR p-value < 0.05 |

### Interpretation

- The FDA statistic captures **curvature** in the trajectory—sudden changes in direction indicate non-monotonic developmental patterns.
- High agreement with permutation test results indicates robust findings.
- FDA may be more sensitive to **non-linear** trajectory changes than the permutation test.

## Interpreting Mixed-Effects Model Results

The mixed-effects model tests for a global trend in effect size across stages while accounting for motif-level variability.

### File: `mixed_effects/mixed_effects_summary.csv`

| Column | Description |
|--------|-------------|
| `stage_coefficient` | Estimated change in effect size per stage |
| `stage_pvalue` | P-value for stage effect |
| `model_converged` | Whether optimization succeeded |

### File: `mixed_effects/mixed_effects_random_effects.csv`

| Column | Description |
|--------|-------------|
| `Motif` | Projection pattern identifier |
| `random_intercept` | Motif-specific deviation from population mean |

### Interpretation

- **stage_coefficient > 0**: Effect sizes tend to increase across development (motifs become more over- or under-represented relative to expectation).
- **stage_pvalue < 0.05**: There is a statistically significant global developmental trend.
- **Marginal p-values (0.05–0.10)**: Suggestive of a trend; consider reporting as exploratory.
- **random_intercept values**: Positive values indicate motifs with consistently higher effect sizes; negative values indicate consistently lower effect sizes.

### Caveats

- This tests a **global** trend, not individual motif trajectories.
- With only 4 stages, power is limited.
- Assumes linear relationship between stage and effect size.

## Interpreting Quadrant-Based Methods

Quadrant methods classify motifs based on whether their position crosses the significance threshold during development. These are **descriptive, not statistical tests**.

### File: `change_criteria_comparison.csv`

| Column | Description |
|--------|-------------|
| `Motif` | Projection pattern identifier |
| `quadrant_change` | Did the motif cross the significance boundary? |
| `path_length` | Raw Euclidean distance traveled in effect/significance space |
| `effect_size_range` | Max - min effect size across stages |
| `path_length_pct` | Percentile rank of path length |
| `effect_size_range_pct` | Percentile rank of effect size range |

### Interpretation

- **quadrant_change = True**: The motif moved from "significant" to "not significant" (or vice versa) at some point during development.
- **This does NOT mean the change is statistically significant**—it only describes what was observed.
- Use quadrant change for exploratory hypothesis generation, not for publication claims.

## Using Distance Metrics

Distance metrics provide continuous measures of trajectory magnitude that avoid arbitrary binary cutoffs.

### File: `distance_metrics/distance_comparison.csv`

| Metric | Description | Best Use |
|--------|-------------|----------|
| `path_length_raw` | Euclidean distance in raw units | Not recommended (mixes scales) |
| `path_length_zscore` | Path length after z-score standardization | **Recommended** for ranking |
| `path_length_mahalanobis` | Path length accounting for covariance | Most sophisticated |
| `effect_size_range` | Range of effect sizes | Biological magnitude |
| `effect_size_sd` | Standard deviation of effect sizes | Variability measure |
| `effect_size_total_variation` | Sum of absolute changes | Cumulative change |
| `significance_range` | Range of -log10(p-values) | Statistical confidence change |
| `*_pct` columns | Percentile rank (0-100) | Relative ranking |

### Recommended Approach

Use `path_length_zscore_pct` to rank motifs by trajectory magnitude:

- **Top 10%**: Largest trajectory changes (may be interesting even if not significant)
- **Top 25%**: Moderate changes worthy of visualization
- **Bottom 50%**: Relatively stable across development

## Interpreting Trend Analysis Results

The trend analysis module (v2.1) provides three complementary tests specifically designed to detect monotonic developmental trends that permutation/FDA tests may miss.

### Spearman Rank Correlation Test

Tests whether effect size consistently increases or decreases across developmental stages.

#### File: `trend_analysis/spearman_trend_results.csv`

| Column | Description |
|--------|-------------|
| `Motif` | Projection pattern identifier |
| `spearman_rho` | Correlation coefficient (-1 to +1) |
| `spearman_pvalue` | Raw two-sided p-value |
| `spearman_pvalue_fdr` | FDR-corrected p-value |
| `spearman_significant` | Boolean: FDR p-value < 0.05 |
| `trend_direction` | "increasing", "decreasing", or "none" |

#### Interpretation

- **spearman_rho = +1.0**: Perfect monotonic increase (effect size increases at every stage)
- **spearman_rho = -1.0**: Perfect monotonic decrease
- **spearman_rho near 0**: No monotonic relationship
- **spearman_significant = True**: The monotonic trend is statistically significant after FDR correction

#### Why Spearman detects trends permutation misses

The permutation test uses total variation as its statistic, which is identical regardless of stage ordering. Spearman specifically tests whether the ordering matters, making it more powerful for detecting monotonic developmental trends.

### Linear Regression Trend Test

Tests for a linear relationship between stage and effect size, providing slope estimates.

#### File: `trend_analysis/linear_trend_results.csv`

| Column | Description |
|--------|-------------|
| `Motif` | Projection pattern identifier |
| `slope` | Estimated change in effect size per stage |
| `intercept` | Y-intercept of regression line |
| `r_squared` | Proportion of variance explained |
| `pvalue` | Raw p-value for slope ≠ 0 |
| `pvalue_fdr` | FDR-corrected p-value |
| `linear_significant` | Boolean: FDR p-value < 0.05 |
| `trend_direction` | "increasing", "decreasing", or "none" |

#### Interpretation

- **slope > 0**: Effect size tends to increase across development
- **slope < 0**: Effect size tends to decrease across development
- **r_squared**: Higher values indicate better fit to linear model
- **linear_significant = True**: The linear trend is statistically significant

#### Caveats

With only 4 time points, linear regression has limited power and degrees of freedom. The Spearman test is generally preferred for detecting trends.

### Global Direction Test (Binomial)

Tests whether more motifs show increasing vs decreasing effect sizes than expected by chance.

#### File: `trend_analysis/direction_test_summary.csv`

| Column | Description |
|--------|-------------|
| `n_increasing` | Number of motifs with effect_size(P60) > effect_size(P12) |
| `n_decreasing` | Number of motifs with effect_size(P60) < effect_size(P12) |
| `n_total` | Total number of motifs tested |
| `proportion_increasing` | Fraction of motifs increasing |
| `binomial_pvalue` | Two-sided binomial test p-value (vs null of 50/50) |
| `direction_bias` | "more_increasing", "more_decreasing", or "no_significant_bias" |

#### File: `trend_analysis/direction_changes_per_motif.csv`

| Column | Description |
|--------|-------------|
| `Motif` | Projection pattern identifier |
| `early_effect_size` | Effect size at P12 |
| `late_effect_size` | Effect size at P60 |
| `change` | late - early |
| `direction` | "increasing" or "decreasing" |

#### Interpretation

- **binomial_pvalue < 0.05**: Significantly more motifs change in one direction than expected by chance
- This tests population-level bias, not individual motif significance
- Even if no individual motif is significant, a consistent direction across motifs may indicate a weak but real biological signal

### Trend Analysis Visualizations

The trend analysis module generates three visualization outputs:

| File | Description |
|------|-------------|
| `slope_distribution.{pdf,svg,png}` | Histogram of linear regression slopes with mean/median lines |
| `direction_pie_chart.{pdf,svg,png}` | Pie chart showing proportion increasing vs decreasing |

### Color Scheme Recommendations

**For binary filtering:**
- Significant/highlighted trajectories: Blue (#3182ce)
- Non-significant/background trajectories: Light gray (#e2e8f0)

**For continuous gradient:**
- Low path length: Light gray
- High path length: Dark blue
- Use `path_length_zscore_pct` scaled to [0, 1] for colormap input

## Strict Verdict: Threshold Crossing Criterion

### Rationale

A statistically significant Spearman trend indicates monotonic change in effect size over development. However, **biological significance** requires that this change be meaningful—the motif should actually change its classification from over- to under-represented, or cross the significance threshold.

Consider a motif like `am+pm` in the noP3 analysis:
- Spearman rho = -1.0 (perfect monotonic decrease)
- FDR-corrected p < 0.05 (statistically significant)
- BUT: The motif remains in the "significantly overrepresented" quadrant throughout development

This motif shows a statistically significant **quantitative** change, but no **qualitative** change in its biological classification. Such motifs are filtered out by the strict verdict criterion.

### Definition

**Strict Verdict** requires BOTH:
1. Spearman significance (FDR < 0.05)
2. Threshold crossing: trajectory crosses EITHER:
   - **P-value cutoff line** (y-axis): Motif transitions between significant and non-significant
   - **Effect size = 0 line** (x-axis): Motif transitions between over- and under-represented

### Output Files

| File | Description |
|------|-------------|
| `motif_verdicts.csv` | Full verdict table with crossing columns |
| `trajectories_by_verdict.png` | All trajectories colored by Spearman significance |
| `trajectories_strict_verdict.png` | All trajectories colored by strict verdict |
| `trajectories_strict_verdict_colored_only.png` | Only strict significant trajectories |
| `trajectories_strict_verdict_grey_only.png` | Trajectories not meeting strict criterion |

### Columns in `motif_verdicts.csv`

| Column | Description |
|--------|-------------|
| `Motif` | Projection pattern identifier |
| `spearman_rho` | Spearman correlation coefficient |
| `spearman_pvalue_fdr` | FDR-corrected p-value |
| `spearman_significant` | Boolean: FDR p-value < 0.05 |
| `direction` | "increasing" or "decreasing" |
| `verdict_label` | "SIGNIFICANT MONOTONIC INCREASE/DECREASE" or "NO CHANGE" |
| `crosses_pvalue` | Boolean: crosses significance threshold |
| `crosses_effectsize` | Boolean: crosses effect size = 0 |
| `crosses_either` | Boolean: crosses at least one threshold |
| `strict_verdict_label` | "SIGNIFICANT + THRESHOLD CROSSING" or "NO MEANINGFUL CHANGE" |

### Interpretation Guide

| Spearman | Crosses Threshold | Interpretation |
|----------|-------------------|----------------|
| Significant | Yes | **Biologically meaningful change** - motif changes classification |
| Significant | No | Statistical trend within same quadrant - quantitative only |
| Not significant | Yes | No consistent trend despite apparent quadrant change |
| Not significant | No | Stable trajectory - no meaningful change |

## Method Agreement Analysis

### File: `method_comparison/method_agreement_matrix.csv`

This matrix shows the percentage agreement between different methods. High agreement between permutation and FDA tests (typically >90%) indicates robust null detection. Lower agreement between formal tests and quadrant methods is expected since they measure different things.

### File: `method_comparison/significant_by_method.csv`

Lists which motifs are flagged by each method, allowing direct comparison of method sensitivity.

### Interpreting Disagreements

| Scenario | Interpretation |
|----------|----------------|
| Permutation significant, quadrant not | Subtle but statistically detectable change |
| Quadrant significant, permutation not | Apparent change may be noise |
| All methods agree: significant | High-confidence finding |
| All methods agree: not significant | Stable trajectory |

## Statistical Conclusions Framework

When reporting trajectory analysis results, consider this framework:

### Strong Claims (require formal test significance)

> "Motif X shows a statistically significant developmental trajectory (permutation test p < 0.05, FDR-corrected)"

### Moderate Claims (marginal significance or high effect size)

> "Motif X shows a suggestive developmental trend (mixed-effects p = 0.059) with the largest trajectory magnitude in the dataset (96th percentile by z-score path length)"

### Descriptive Observations (no significance)

> "Several motifs exhibited quadrant changes during development, though none reached statistical significance after multiple testing correction. This may reflect limited power with n=4 developmental stages."

### Null Results (important to report)

> "Permutation testing found no individual motif trajectories distinguishable from random variation (all FDR p > 0.05), suggesting developmental changes in projection patterns may be modest or variable across animals."

---

## Power Considerations

With typical MAPseq experimental designs (4 developmental stages, ~20-30 motifs), statistical power for trajectory detection is limited. Consider:

1. **Sample size**: More stages or replicate animals would increase power
2. **Effect size**: Larger biological effects are easier to detect
3. **Multiple testing burden**: Testing many motifs reduces sensitivity per motif

A non-significant result does not prove absence of developmental change—it indicates the data cannot distinguish the observed pattern from noise.

---

## Recommended Workflow

1. **Start with formal tests**: Check permutation and FDA results for any significant trajectories
2. **Check trend analysis**: Review Spearman results for monotonic trends (may detect patterns permutation misses)
3. **Examine mixed-effects model**: Assess global developmental trend
4. **Check direction test**: Determine if there is population-level directional bias
5. **Review distance metrics**: Identify motifs with largest trajectory magnitudes
6. **Use quadrant methods**: Generate hypotheses for motifs of potential interest
7. **Create visualizations**: Use appropriate filtering tier for intended audience
8. **Report honestly**: Distinguish between statistical significance and descriptive observations

### Significant Motifs: Detailed Analysis

Two motifs reached statistical significance for monotonic trends:

**1. am+pm+rsp** (anteriomedial + posteriomedial + retrosplenial)
- Spearman rho = 1.0 (perfect monotonic increase)
- FDR-corrected p < 0.05
- Effect size change: P12 = 1.76 → P60 = 2.84 (+1.08)
- Linear regression p = 0.074 (marginal)

**2. al+am+pm+rsp** (anteriolateral + anteriomedial + posteriomedial + retrosplenial)
- Spearman rho = 1.0 (perfect monotonic increase)
- FDR-corrected p < 0.05
- Effect size change: P12 = -0.23 → P60 = 1.65 (+1.87)
- Linear regression p = 0.050 (marginal)

**Notable pattern**: Both significant motifs share the am+pm+rsp projection combination, suggesting this specific three-region pattern may represent a biologically meaningful developmental signal.

### Verdict on the Hypothesis

**Per-Motif Summary:**
- **24/26 motifs (92%)**: NO statistically significant developmental change detected by any test
- **2/26 motifs (8%)**: Significant monotonic increasing trend detected by Spearman test

**Global Summary:**
- No significant directional bias across the population (binomial p = 0.327)
- Marginally non-significant global trend (mixed-effects p = 0.059)
- Apparent quadrant changes (13/26 motifs) are descriptive only and not statistically validated

**Conclusion:**

The hypothesis is **largely supported**. The vast majority of multi-area projection motifs (24/26, 92%) show no statistically significant developmental trajectory when tested with rigorous statistical methods including permutation tests, FDA, Spearman correlation, and linear regression.

Two exceptions exist: **am+pm+rsp** and **al+am+pm+rsp** both show perfect monotonic increasing trends (Spearman rho = 1.0, FDR-corrected p < 0.05). Both motifs share the am+pm+rsp regional combination, suggesting this specific projection pattern may have a genuine developmental signal worthy of biological investigation.

The apparent changes observed in other motifs—including the 13 motifs showing quadrant changes—cannot be distinguished from random variation given the current sample size of 4 developmental stages. The marginally significant mixed-effects result (p = 0.059) hints at a weak global tendency toward more extreme effect sizes over development, but this does not reach conventional significance thresholds.

### Interpretation of noP3 Results

The dramatic increase in significant Spearman correlations (from 2 to 10) when excluding P3 is primarily a **statistical artifact** of having only 3 time points:

1. **With 3 points, perfect correlations are common**: Any consistent ordering (always increasing or always decreasing across P12→P20→P60) yields rho = ±1.0
2. **The test becomes more liberal**: Fewer degrees of freedom make it easier to achieve significance
3. **P3 data adds variability**: Including P3 introduces an additional time point that can break perfect monotonic patterns

**Biological interpretation**: The noP3 analysis reveals which motifs show consistent directional change between P12 and P60, regardless of P3 behavior. However, these results should be considered **exploratory** rather than confirmatory due to the limited statistical power.
